# 网球测试版与水瓶正式版分离说明

## 网球测试版（冻结的 58/58 时期行为）

入口：

```bash
bash run_tennis_placement_debug.sh 21
```

该入口不再转调水瓶正式版，而是使用独立资源：

- `actions/tennis_debug/`：控制器、视觉、身份关联、场景生成等模块的完整副本；
- `vision_sorting_tennis_debug.yaml`：`0.65、0.58、0.51、0.44、0.37、0.30 m`
  放置序列以及旧版 `5 cm` 回中区域；
- `pick_place_tennis_debug.sdf`：`1.20 × 0.80 m` 红/绿 marker；
- `vision_sorting_tennis_debug.launch.py` 与
  `static_model_tennis_debug.launch.py`：独立启动链；
- `models/tennis_debug/056_tennis_ball/`：5.4 cm 碰撞体使用的独立网球资源；
- `team21_tennis_debug_*`：独立 Gazebo transport partition；
- `ROS_DOMAIN_ID=122`：与正式版默认的 `121` 隔离；
- `logs/tennis_debug/`：独立日志目录。

这个版本没有水瓶正式版后来加入的 `COARSE WORLD-BEARING ALIGN`，因此不会
再因那段世界坐标粗转向造成网球转过头。网球视觉比例仍为 `93%`，生成高度
仍为 `2.7 cm`。

## 水瓶正式版

入口：

```bash
bash run_vision_sorting_improved.sh 21 nominal
```

正式版保留淡蓝水瓶、置信度颜色奖励、固定世界原点和扩大后的放置区域。
分类转向增加了强制轮速契约：

- 水瓶：`-90°`，顺时针向右；
- 网球：`+90°`，逆时针向左；
- 转向时左侧两轮同速、右侧两轮同速，左右两侧等速反向，线速度严格为零；
- 如果控制器未来生成弧线转弯轮速，程序会立刻拒绝该命令并安全停止。

运行日志可用以下字段确认：

```text
CLASS-SPECIFIC IN-PLACE TURN | class=bottle | direction=CLOCKWISE/RIGHT
CLASS-SPECIFIC IN-PLACE TURN | class=tennis | direction=COUNTERCLOCKWISE/LEFT
```

两个版本均在本地工作区与 `try/recommended_overlay/digital` 保存，没有执行
GitHub push。
